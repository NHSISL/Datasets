## Summary

This release introduces major new functionality for exporting NDOO and PDS request data, including robust batch export workflows, enhanced Azure integration, and optional encryption support for secure data handling. The update also brings improvements to model organization, request-response tracking, and configuration consistency, laying the groundwork for scalable and secure data operations. Additionally, package dependencies have been updated to their latest release versions for improved stability and compatibility.

### Dependency changes

- OLIDS_SHARE: [v1.2.0](../1_OLIDS_Share/v1.2.0.md)  (⬆️ upgrade)
- EMIS_OLIDS: [v2.0.0](../2_EMIS_OLIDS/v2.0.0.md) (⬆️ upgrade)

### New Features

- Add NDOO and PDS request export functionality, including batch export procedures, new dbt models for request logging, optional encryption for Azure-bound exports, and dedicated file formats and external stages. *[PR: [#39](https://github.com/NHSISL/LondonDataservices.Transform.OLIDS_Enrichment/pull/39)]*
  > ✨ ***Feature:*** Enables automated, scalable export of unsent NDOO and PDS requests with support for secure, encrypted file delivery to Azure, improving interoperability and auditability.
  > <br>Addresses known Issue [AB29779 - KI-01: static PDS, UPRN and NDOO records](https://dev.azure.com/NELAnalytics/LondonDataService/_workitems/edit/29779)

### Improvements

- Update package revisions to release versions. *[PR: [#49](https://github.com/NHSISL/LondonDataservices.Transform.OLIDS_Enrichment/pull/49)]*
  > 🎯 ***Impact:*** Ensures compatibility and stability by aligning all package dependencies with their latest release versions.

- Enhance PDS and NDOO request handling with deduplication logic, improved trace request management, and comprehensive request-response exchange tracking. *[PR: [#39](https://github.com/NHSISL/LondonDataservices.Transform.OLIDS_Enrichment/pull/39)]*
  > 🎯 ***Impact:*** Reduces duplicate requests, improves traceability, and streamlines the request-response lifecycle for better data quality and operational reliability.
  ><br>Addresses known issue [AB#29792 KI-06 Patients will only ever match to PDS resposnes that share the same NHS number](https://dev.azure.com/NELAnalytics/LondonDataService/_workitems/edit/29792)

- Adds LDS_SOURCE_DATASET column to PERSON model for clearer lineage of data source
  >Addresses bug raised: [AB#29841 - MATCHED_NHS_NO field populated when no match has occurred](https://dev.azure.com/NELAnalytics/LondonDataService/_workitems/edit/29841)

- Update dbt project configuration to register new models, schemas, and macro test tagging. *[PR: [#39](https://github.com/NHSISL/LondonDataservices.Transform.OLIDS_Enrichment/pull/39)]*
  > 🎯 ***Impact:*** Simplifies model management and enhances testing capabilities for more robust data workflows.

- Introduce NHS number masking rules and additional tests for new PDS request/responses models. *[PR: [#39](https://github.com/NHSISL/LondonDataservices.Transform.OLIDS_Enrichment/pull/39)]*
  > 🎯 ***Impact:*** Strengthens data privacy controls and ensures compliance with sensitive data requirements.
