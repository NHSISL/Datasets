## Summary

This release introduces significant enhancements to data handling and schema support within the platform. Key additions include new macros for robust date parsing, formatting, and person business ID generation, improving consistency across Snowflake and DuckDB adapters. The release also adds a new allocation table schema and data, and expands row-level security policy flexibility. These changes collectively enhance data accuracy, maintainability, and security policy management for users.

### New Features

- Add allocation table schema and actual data. *[PR: [#12](https://github.com/NHSISL/LondonDataServices.OLIDS_Share/pull/12)]*
  > ✨ ***Feature:*** Introduces a new internal allocation table schema with associated data for record access policy application.

- transfer macros: `generate_person_business_id`. *[PR: [#9](https://github.com/NHSISL/LondonDataServices.OLIDS_Share/pull/9)]*

  > ✨ ***Feature:*** Provides centrallised robust and standardized macros for business ID generation. (Transferred across from EMIS_OLIDS repo)

- Add macros: `format_date_to_string`, `parse_pds_date`, and `pds_date_precision`. *[PR: [#9](https://github.com/NHSISL/LondonDataServices.OLIDS_Share/pull/9)]*

  > ✨ ***Feature:*** Provides robust and standardized macros for date formatting, and PDS date precision detection

### Improvements

- Enhance row access policy creation macro to support both "lookup" and new "direct" policy kinds. *[PR: [#9](https://github.com/NHSISL/LondonDataServices.OLIDS_Share/pull/9)]*
  > 🎯 ***Impact:*** Increases flexibility and efficiency in defining row-level security policies, allowing for more granular and adaptable access control. Provides dedicated RAP for person object to resolve [AB#29839 Missing persons in person table](https://dev.azure.com/NELAnalytics/LondonDataService/_workitems/edit/29839)

- Refactor and standardise date handling macros to utilise new parsing and precision detection logic. *[PR: [#9](https://github.com/NHSISL/LondonDataServices.OLIDS_Share/pull/9)]*
  > 🎯 ***Impact:*** Improves the accuracy and maintainability of date extraction and interpretation, reducing errors and ensuring correct handling of PDS/EMIS date fields across adapters.
